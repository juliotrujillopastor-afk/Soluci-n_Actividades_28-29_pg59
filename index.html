Resolución de Ejercicios: Ecuaciones Racionales y con Radicales

Actividad 28. Resuelve estas ecuaciones racionales convirtiéndolas en ecuaciones polinómicas. Comprueba las soluciones.

a)   1⁄x - 5⁄x2 + 6⁄x3 = 0
1. Dominio de definición:

Los denominadores no pueden ser nulos: x ≠ 0.

2. Conversión a ecuación polinómica:

Multiplicamos toda la ecuación por el mínimo común múltiplo de los denominadores, m.c.m. = x3:

x3 · (1/x - 5/x2 + 6/x3) = 0 · x3
x2 - 5x + 6 = 0
3. Resolución de la ecuación de segundo grado:
x = [-(-5) ± √((-5)2 - 4·1·6)] / (2·1)
x = [5 ± √(25 - 24)] / 2 = (5 ± 1) / 2

x1 = (5 + 1) / 2 = 3
x2 = (5 - 1) / 2 = 2
4. Comprobación:
  • Para x = 3: 1/3 - 5/9 + 6/27 = 9/27 - 15/27 + 6/27 = 0/27 = 0. VÁLIDA
  • Para x = 2: 1/2 - 5/4 + 6/8 = 4/8 - 10/8 + 6/8 = 0/8 = 0. VÁLIDA

Soluciones: x = 3, x = 2

b)   x⁄x+1 + x+1⁄x = 8x+1⁄x2+x
1. Dominio de definición:

Dado que x2 + x = x(x + 1), las restricciones son: x ≠ 0 y x ≠ -1.

2. Conversión a ecuación polinómica:

El m.c.m. de los denominadores es x(x + 1) = x2 + x. Multiplicamos todos los términos por este m.c.m.:

x·x + (x + 1)(x + 1) = 8x + 1
x2 + (x2 + 2x + 1) = 8x + 1
2x2 + 2x + 1 = 8x + 1
2x2 - 6x = 0
2x(x - 3) = 0
3. Posibles soluciones:
2x = 0 ⇒ x = 0
x - 3 = 0 ⇒ x = 3
4. Comprobación:
  • Para x = 0: Anula los denominadores (x y x2+x). NO VÁLIDA (Extraña)
  • Para x = 3: 3/(3+1) + (3+1)/3 = 3/4 + 4/3 = 25/12.
    Lado derecho: (8·3 + 1)/(32 + 3) = 25/12. VÁLIDA

Solución única: x = 3

c)   x3 - 1⁄x3 = 15 624⁄125
1. Dominio y cambio de variable:

Restricción: x ≠ 0. Aplicamos el cambio de variable t = x3:

t - 1/t = 15624 / 125
2. Conversión a ecuación polinómica:

Multiplicamos toda la ecuación por 125t:

125t2 - 125 = 15624t
125t2 - 15624t - 125 = 0
3. Resolución de la cuadrática en t:
t = [15624 ± √((-15624)2 - 4·125·(-125))] / (2·125)
t = [15624 ± √(244 109 376 + 62 500)] / 250
t = [15624 ± √244 171 876] / 250 = (15624 ± 15626) / 250

t1 = 31250 / 250 = 125
t2 = -2 / 250 = -1 / 125
4. Deshacer el cambio de variable (x = 3√t):
Si t = 125 ⇒ x = 3√125 = 5
Si t = -1/125 ⇒ x = 3√(-1/125) = -1/5
5. Comprobación:
  • Para x = 5: 53 - 1/53 = 125 - 1/125 = (15625 - 1)/125 = 15624/125. VÁLIDA
  • Para x = -1/5: (-1/5)3 - 1/(-1/5)3 = -1/125 + 125 = 15624/125. VÁLIDA

Soluciones: x = 5, x = -1/5

d)   x-1⁄x + x-3⁄x-4 = 2x-3⁄x-1
1. Dominio de definición:

Restricciones: x ≠ 0, x ≠ 4, x ≠ 1.

2. Conversión a ecuación polinómica:

Multiplicamos por el m.c.m. = x(x - 4)(x - 1):

(x - 1)·(x - 4)(x - 1) + (x - 3)·x(x - 1) = (2x - 3)·x(x - 4)

• (x - 1)2(x - 4) = (x2 - 2x + 1)(x - 4) = x3 - 6x2 + 9x - 4
• x(x - 3)(x - 1) = x(x2 - 4x + 3) = x3 - 4x2 + 3x
Suma Izquierda: 2x3 - 10x2 + 12x - 4

• Lado Derecho: x(2x - 3)(x - 4) = x(2x2 - 11x + 12) = 2x3 - 11x2 + 12x
3. Igualación y simplificación:
2x3 - 10x2 + 12x - 4 = 2x3 - 11x2 + 12x
-10x2 - 4 = -11x2
x2 - 4 = 0 ⇒ x2 = 4 ⇒ x = ±2
4. Comprobación:
  • Para x = 2: (2-1)/2 + (2-3)/(2-4) = 1/2 + 1/2 = 1. L.D.: (2·2-3)/(2-1) = 1/1 = 1. VÁLIDA
  • Para x = -2: (-2-1)/(-2) + (-2-3)/(-2-4) = 3/2 + 5/6 = 14/6 = 7/3. L.D.: (2(-2)-3)/(-2-1) = -7/(-3) = 7/3. VÁLIDA

Soluciones: x = 2, x = -2

Actividad 29. Resuelve las siguientes ecuaciones con radicales. No olvides comprobar las soluciones.

a)   √(x - 1) = 13
1. Elevar al cuadrado ambos miembros:
(√(x - 1))2 = 132
x - 1 = 169
x = 169 + 1 = 170
2. Comprobación:
√(170 - 1) = √169 = 13. VÁLIDA

Solución: x = 170

b)   √(7x - 3) = 2x - 3
1. Elevar al cuadrado ambos miembros:
(√(7x - 3))2 = (2x - 3)2
7x - 3 = 4x2 - 12x + 9
4x2 - 19x + 12 = 0
2. Resolver la ecuación cuadrática:
x = [19 ± √((-19)2 - 4·4·12)] / (2·4)
x = [19 ± √(361 - 192)] / 8 = (19 ± √169) / 8 = (19 ± 13) / 8

x1 = (19 + 13) / 8 = 32 / 8 = 4
x2 = (19 - 13) / 8 = 6 / 8 = 3/4
3. Comprobación:
  • Para x = 4: √(7·4 - 3) = √25 = 5. L.D.: 2(4) - 3 = 5. (5 = 5) VÁLIDA
  • Para x = 3/4: √(7(3/4) - 3) = √(9/4) = 3/2. L.D.: 2(3/4) - 3 = 6/4 - 3 = -3/2. (3/2 ≠ -3/2) NO VÁLIDA (Falsa)

Solución única: x = 4

c)   x + √(10x - 4) = 10
1. Aislar el radical y elevar al cuadrado:
√(10x - 4) = 10 - x
(√(10x - 4))2 = (10 - x)2
10x - 4 = 100 - 20x + x2
x2 - 30x + 104 = 0
2. Resolver la ecuación cuadrática:
x = [30 ± √((-30)2 - 4·1·104)] / 2
x = [30 ± √(900 - 416)] / 2 = (30 ± √484) / 2 = (30 ± 22) / 2

x1 = (30 + 22) / 2 = 52 / 2 = 26
x2 = (30 - 22) / 2 = 8 / 2 = 4
3. Comprobación:
  • Para x = 26: 26 + √(10·26 - 4) = 26 + √256 = 26 + 16 = 42 ≠ 10. NO VÁLIDA (Falsa)
  • Para x = 4: 4 + √(10·4 - 4) = 4 + √36 = 4 + 6 = 10. (10 = 10) VÁLIDA

Solución única: x = 4

d)   √(x - 5) + √(3x + 7) = 10
1. Aislar un radical y elevar al cuadrado (1.ª vez):
√(3x + 7) = 10 - √(x - 5)
(√(3x + 7))2 = (10 - √(x - 5))2
3x + 7 = 100 - 20√(x - 5) + (x - 5)
3x + 7 = 95 + x - 20√(x - 5)
2. Aislar el segundo radical y simplificar:
20√(x - 5) = 88 - 2x
10√(x - 5) = 44 - x (dividiendo por 2)
3. Elevar al cuadrado (2.ª vez):
(10√(x - 5))2 = (44 - x)2
100(x - 5) = 1936 - 88x + x2
100x - 500 = x2 - 88x + 1936
x2 - 188x + 2436 = 0
4. Resolver la ecuación cuadrática:
x = [188 ± √((-188)2 - 4·1·2436)] / 2
x = [188 ± √(35344 - 9744)] / 2 = (188 ± √25600) / 2 = (188 ± 160) / 2

x1 = (188 + 160) / 2 = 348 / 2 = 174
x2 = (188 - 160) / 2 = 28 / 2 = 14
5. Comprobación:
  • Para x = 174: √(174 - 5) + √(3·174 + 7) = √169 + √529 = 13 + 23 = 36 ≠ 10. NO VÁLIDA (Falsa)
  • Para x = 14: √(14 - 5) + √(3·14 + 7) = √9 + √49 = 3 + 7 = 10. (10 = 10) VÁLIDA

Solución única: x = 14
